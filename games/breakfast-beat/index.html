Breakfast Beat

Breakfast Beat is a rhythm-infused tower-defence game set on a breakfast line. Place food-themed defences against incoming snack waves; lanes map to chord notes and tower columns fire in sequence, turning a defence layout into a musical grid.

Play on itch.io -> Featured in Samfa12's TD Pack ->

Defend in time with the music

The itch page describes Egg Shakers, Toast Stacks, Yolk Bombs and Bacon Blasters. It says surviving twelve waves unlocks Endless Mode, and that different chords can be selected.

Included in the Android pack

The Google Play destination is Samfa12 Tower Defense Pack, a collection listing Breakfast Beat with four other games. It is not a separate Play listing for Breakfast Beat.

Questions about Breakfast Beat

How does music relate to the tower defence?

The itch description says each lane corresponds to a chord note and each column fires on a step in the sequence, so the placed defences create a musical pattern.

Where is the Android version listed?

Breakfast Beat is listed as part of Samfa12 Tower Defense Pack on Google Play; the pack listing is the destination, not a standalone game listing.
