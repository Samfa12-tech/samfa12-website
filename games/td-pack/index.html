Samfa12's TD Pack

Samfa12 Tower Defense Pack is an Android collection of bite-sized tower-defence games. The Google Play listing names Breakfast Beat, Ship Blockade, Bug Maze TD, Coop Guard TD and Library Lockdown TD, each with its own theme, towers, enemies and music.

Get it on Google Play ->

Five games in one collection listing

The current Play About section lists five included games and describes offline play, short levels, shared launcher/settings/audio controls and no ads, accounts or data collection. Its What's New text separately refers to “all six included games,” which conflicts with that five-title list; the count should be treated as unresolved until the publisher clarifies it.

Questions about Samfa12's TD Pack

Which games does the listing name?

The current About section names Breakfast Beat, Ship Blockade, Bug Maze TD, Coop Guard TD and Library Lockdown TD. The same listing's What's New section says “all six included games,” so its count is internally inconsistent.

Are the constituent itch games separate Android store pages?

The individual catalogue links for Breakfast Beat, Ship Blockade and Bug Maze TD lead to this pack listing. It is a collection destination, not an individual app page for each game.
