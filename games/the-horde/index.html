The Horde — Ray Tracing Tech Demo

The Horde is a focused native Vulkan hardware ray-tracing technology demo for compatible Windows RT GPUs and Android phones. Its current itch description follows a lantern-bearing character through a wet gothic ruin, with sword combat, reflective water and a lich encounter.

Download on itch.io -> Source on GitHub ->

A technology showcase, not a complete game

The publisher describes The Horde as a focused tech demo. It says the demo uses Vulkan acceleration structures and ray-tracing commands, and has no raster, browser, baked, screen-space or simulated ray-tracing fallback.

Compatibility is hardware-dependent

The page names compatible Android phones and Windows RT GPUs as target platforms, but it does not provide a verified device compatibility list. Do not infer support for a particular phone or GPU from the general platform label.

Questions about The Horde — Ray Tracing Tech Demo

Can I play this in a browser?

No browser version is listed. The publisher explicitly says this demo has no browser or simulated ray-tracing fallback.

Will it run on my Android phone?

Only if the phone supports the required Vulkan hardware ray-tracing features. The listing does not confirm compatibility for every model; check the project source and device support before installing.
