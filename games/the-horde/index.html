The Horde — Ray Tracing Tech Demo

The Horde 1.6.2 is a native Vulkan hardware ray-tracing tomb demo for Windows and compatible Android phones. Explore a torch-lit gothic ruin, fight skeletons and confront the Lich, with reflective water, an adaptive soundtrack and a new lantern-lit menu.

Download on itch.io -> Source on GitHub ->

A technology showcase, not a complete game

The publisher describes The Horde as a focused tech demo. It says the demo uses Vulkan acceleration structures and ray-tracing commands, and has no raster, browser, baked, screen-space or simulated ray-tracing fallback.

Graphics you can preview and keep

A live ray-traced Graphics preview lets you compare render scale, water, fire, glass, mist and dust before keeping or restoring your settings. New Android installs start at 50% render scale with Mobile water and fire, glass off, mist on and Low dust. Windows starts at 100%, High water and fire, glass on, mist on and Low dust. Existing settings are preserved; 33% and 40% scales are experimental.

Touch controls, controllers and the tomb

Swing, Parry and Dodge touch buttons accompany a heart-based health display. Android controller support covers menus, gameplay and reconnects. The sword starts sheathed and draws at the waterfall guards, with improved equipment clearance. The update also adds subtle dust, torch-lit waterfall refinements, a closed base beneath the grate and collision for the Keeper’s torch stands.

Hardware and testing limits

Windows requires Windows 10/11 and a Vulkan-capable hardware ray-tracing GPU. The published 1.6.2 build has recorded checks on a Galaxy S26 Ultra and an RTX 5050 Laptop GPU. Earlier S24 Ultra testing does not certify this release on every device; S25 Ultra remains unverified. Backbone One PlayStation Edition USB-C is the tested Android controller, with other combinations still needing coverage. Sustained 30 FPS is not guaranteed. Combat remains forgiving: a hit can register before exact visible blade contact.

Questions about The Horde — Ray Tracing Tech Demo

Can I play this in a browser?

No browser version is listed. The publisher explicitly says this demo has no browser or simulated ray-tracing fallback.

Will it run on my Android phone?

The phone needs the required Vulkan hardware ray-tracing features. Release 1.6.2 was checked on a Galaxy S26 Ultra; other models are not all verified. The official listing describes earlier Galaxy S24 Ultra testing and lists S25 Ultra support as expected, pending physical testing. Performance depends on your device and settings.

Where can I get version 1.6.2?

Download the Windows build or Android APK from the official itch.io page. Version 1.6.2 is published there; the GitHub repository provides source and technical documentation.

Updates

Now available for Windows and Android, 1.6.2 adds a lantern-lit menu, live graphics preview, reworked touch controls and Android controller support. The engineering update adds dedicated ray-traced viewmodel arms and a separately owned player body, adaptive music with separate audio controls, consent-based in-game reporting, and resource and lifecycle improvements. The release is available for Windows and Android.
