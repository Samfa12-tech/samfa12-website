How to read these results

FPS means frames per second. Higher values usually mean smoother motion. An estimate gives an indication of performance; it is not a measured gameplay frame rate.

Average FPS is not in the current reports. The FPS estimate shown here uses the typical recorded rendering time. A typical value is a median, so it cannot tell us the average. We show the missing average explicitly rather than guess it.

Different settings change the workload. Compare resolution, graphics settings and game build before drawing conclusions. These are custom test runs, not a verified leaderboard. Each card stays separate, even when the hardware name matches.

Reports are shared by players and have not been independently checked. Multiple reports may come from the same person or device. Open a result’s details for its original timings, build and test configuration.
