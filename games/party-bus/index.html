P.A.R.T.Y. Bus: Wasteland Run

P.A.R.T.Y. Bus: Wasteland Run is a 3D browser driving-survival prototype about taking a battered yellow bus into hostile territory and getting survivors and supplies back to base. Damage, cargo weight, enemies and fuel all add pressure to the return trip.

Play on itch.io ->

Scavenge and bring people home

The current itch page's v0.9 description lists the Rust Mile route, scrap and fuel scavenging, survivor rescues, hostile encounters, manual turn-back and visible bus upgrades. It says the prototype has desktop and mobile touch controls.

Prototype status

The catalogue calls the game in development; the itch page describes its current build as a browser prototype. These descriptions do not verify future roadmap features.

Questions about P.A.R.T.Y. Bus: Wasteland Run

Can I choose when to head back?

The current build description says the player can turn back manually and survive the ride home.

Is this a finished release?

The publisher describes it as a 3D browser prototype and identifies the current build as v0.9.
