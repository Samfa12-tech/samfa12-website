Bug Swarm

Bug Swarm is a phone-oriented tower-defence prototype about placing towers beside a curved dirt-tray path and responding as waves of bugs flood through it. Its local game menu shows a Leaf 1k flood and additional prototype levels that begin locked.

Play now ->

Build beside the bug path

The current browser runtime describes a curved dirt-tray maze, DIY towers and player tools including Poke and Burn. It lists ants, roaches and beetles as enemy mixes, with a workbench upgrade tree and Bug Bucks and Rare Parts as progression resources.

A phone prototype with larger tests still marked as prototype

The menu labels its flood levels as prototypes: Leaf 1k is available in the default menu while Biscuit 2.5k, Crayon 5k, Button 7.5k and Toybox 10k appear locked. A separate Lab mode is labelled for browser stress testing. These labels do not establish supported performance on phones at those swarm sizes.

Questions about Bug Swarm

How do I place towers and use tools?

The runtime instructions say to select a tower and tap beside the path to place it. During a flood, select a tool such as Poke or Burn and use it on the bugs.

Are all five flood levels unlocked?

No. The current menu calls them prototype flood levels; Leaf 1k is available by default and the higher named levels show as locked. Lab mode is separately labelled for browser stress testing.
