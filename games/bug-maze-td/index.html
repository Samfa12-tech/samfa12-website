Bug Maze TD

Bug Maze TD is a portrait-first tower-defence game for mobile browsers. Build paths and place bug-themed towers across handcrafted garden levels, while ground and flying enemies follow different routes.

Play on itch.io -> Featured in Samfa12's TD Pack ->

Build a maze through the garden

The itch page describes four handcrafted levels, multiple enemy types, towers with different roles, level-specific themes and music, and speed options. The browser game can save a run and continue later.

The Android link is a collection

Bug Maze TD is included in Samfa12 Tower Defense Pack on Google Play. That Play listing is for the five-game collection, not a standalone Android listing for Bug Maze TD.

Questions about Bug Maze TD

Can ground and flying enemies be blocked by the same maze?

The itch description says ground enemies path around the maze while flying enemies ignore it and head straight through.

Is the Google Play link a separate Bug Maze TD app?

No. It opens Samfa12 Tower Defense Pack, whose listing includes Bug Maze TD alongside other tower-defence games.
