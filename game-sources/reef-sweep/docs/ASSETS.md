# Art, assets and provenance

## Actual assets in this package

All reef, creature and first-person geometry is generated by the project's own `src/render/geometry.ts`/`renderer.ts`; shaders are in `shaders.ts`. These are original first-pass assets, not downloaded stock models and not final production GLBs. There is no runtime texture/model/voice download. The included screenshots are captures of this game running in Babylon, not promised target art.

Babylon runtime source is the only substantial third-party rendering dependency. The source-map carrier's sample scene, models, environment maps and other assets are not shipped. The exact user-provided Pocket Chordsmith editor is a reference asset with its own ownership; do not assign it an unrelated public license.

## Visual direction

Sea-glass blues, warm sand, restrained coral accents, recognisable fish silhouettes and a sparse nautical interface. Creature proportions should become more convincing as the art is refined; avoid turning groupers into comic attack monsters. Light patterns should reveal the seabed and contours, not cover every object with a bright equal-strength lattice.

Priority order: readable lionfish and native silhouettes; comfortable camera/equipment; coherent reef composition; convincing swim motion; surface/depth effects; density. Large schools and a few carefully posed hero animals create more life than indiscriminately adding detail.

## Model import contract for Codex

GLB/glTF 2.0 is the preferred eventual shipping format. Record units, origin, forward axis, material count, triangle count and animation names for each asset. Keep source files and licenses outside the runtime distribution. Target a modest mobile budget; profile the complete scene rather than approving assets by isolated triangle count.

Use local asset paths and a stable manifest. Meshy or other generated replacements need provenance and a visual review; generation success is not topology/rig/texture QA. Add collision proxies separately. Avoid embedding hundreds of individual unbatched coral nodes. Use a shared texture atlas/material family where appropriate.

Final performance ceilings should come from hardware measurements. The current geometry is a starting reference, not a promise that every phone can render the high-quality scene at a particular frame rate.

## v0.5 expedition authoring

The dive skiff is original Blender 5.2 work in art/dive-skiff/lantern-dive-skiff.blend, authored by scripts/author-dive-boat.py. Its lofted hull, liner, foredeck, console, helm, windshield, seats, ice chest, tank rack, outboard, propeller, ladder, rails, cleats and bimini use reused materials and no external textures/assets. The GLB exchange export and two studio render views are retained. Runtime uses src/render/assets/dive-skiff.ts, a deterministic vertex-colour bake: 6,774 triangles, one draw, metres, +Y up and +Z bow, origin at the waterline. This matches the pinned offline engine closure without adding a GLTF loader/runtime dependency. Boat navigation owns its XZ envelope; no new dynamic physics dependency.

Stars, lobsters, sponges, habitat chairs and the five charm designs are original local procedural geometry in marine-life.ts. Ocean lighting/wake/spray and mask overlays are local shader/CSS work. No paid or remotely generated assets, real channel footage, logos or new licenses were added.

## Crown-of-thorns field-response model
Original Blender 5.2 asset under art/crown-of-thorns. The 13-arm smooth continuous body, bent arm tips and short angled papillae are authored by scripts/author-crown-of-thorns.py. Editable blend, GLB, studio evidence and manifest retained. Runtime bakes 2,652 triangles, one colour draw, no textures, in src/render/assets/crown-of-thorns.ts. It is separate from the small orange five-arm ambient sea star. No external assets or paid generation.

## Coastal seagulls (v0.5.0-preview.2)
Original local vertex-colour geometry in src/render/seagulls.ts: pale body/head, swept cambered wings, dark primary tips, small beak/tail and tucked legs. Three to five bounded meshes share one material. Slow elliptical flight and shader wingbeats are render-only, hidden underwater/night; reduced motion suppresses wingbeats. No external assets, textures, paid generation or new runtime services.

## Boat crew and entry

Original Samfa12 cloud Blender production, referenced to the existing unchanged skiff. Editable art/boat-entry/reef-crew-entry.blend, crew-only animated GLB, source scripts/author-boat-entry.py and src/render/assets/boat-entry.ts are retained. The current runtime uses two batched Geometry draws with sampled rigid-part transforms; no new loader, textures, purchased assets or services. Supplied manifest/clearance evidence and README stay alongside the source. See BOAT_ENTRY_INTEGRATION.md.

## Lionfish anatomical remodel and defensive display

Original cloud Blender asset: art/lionfish retains editable blend, GLB, authoring/contract scripts, hinges, GLSL and validation. Runtime src/render/assets/lionfish-mesh.ts has 5539 vertices / 8125 triangles; source geometry stays in authoring units and world fish apply size times .65 once. All scene lionfish share one static GPU geometry, with per-draw shader flare and identical colour/depth deformation. No new loader/textures. The larger triangle count requires physical-phone acceptance; see LIONFISH_INTEGRATION.md.
