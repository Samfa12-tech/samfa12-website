What Would Win

What Would Win is a mock-serious text simulator for one creature against another or a group. Its public project description says a numerical engine determines the result using a deterministic model with seeded Monte Carlo variation; generated narration does not choose the winner.

Use now -> Source on GitHub ->

A simulator, not a prediction authority

The repository describes structured creature profiles, abilities and counters, and says the numerical engine is authoritative for each simulated matchup. Results are produced by the model and random variation, not by the generated text. The project does not claim scientific predictive accuracy for real-world fights.

Custom profiles and reproducible shares

The public README describes saveable private custom profiles and versioned reproducible shares. It also documents simulation and data specifications; use the app's own current explanation for how a particular matchup is modelled.

Questions about What Would Win

Does AI text decide who wins?

No. The repository says the numerical engine determines the outcome; generated text does not choose or alter the winner.

Should I treat a result as a scientific prediction?

No. The public project describes a creature matchup simulator and its model, not a validated scientific predictor of real-world outcomes.
