- A public repository can be viewed and forked under GitHub's terms, but public visibility is not a general licence to reuse its contents.
- `private: true` in an npm package prevents accidental package publication; it does not make this GitHub repository private and is not a content licence.
- Catalogue categories such as Games, Books, Apps & Tools, Assets and Music describe the content, not reuse permissions.
- Existing licences and permissions, including those attached to earlier releases, remain in effect according to their terms. This notice is not a retroactive revocation.
