Pocket DAW

Pocket DAW is a Windows desktop music-workflow alpha. Import Pocket Chordsmith songs, arrange audio and MIDI, record takes and export WAV, MIDI or game-audio ZIPs.

Download from itch.io ->

Arrange, record and compare

Version 0.6.59 adds Campfire Acoustic, finite Hear this bit auditions and Finish & Compare. Prepare an edit without autoplay, compare the same passage at matched levels, then apply, discard or undo it. Native recording, audio/MIDI take lanes, project media collection and optional VST3 hosting support the arrangement workflow.

Export for listening or a game

Export WAV and MIDI, stems, section loops, or Godot and Web game-audio ZIPs. The native DAW pack follows the arranged timeline, including recording media, effects, automation and tails. Check WAV provides measured delivery guidance; target-game audio and timing still need testing in the game.

Windows alpha

Pocket DAW remains an early Windows alpha. Keep backups of important projects and verify exports before delivery. The installer has an updater signature but is not Windows Authenticode signed, so Windows may show a warning. Get it through the established itch download or the official GitHub release.

Questions about Pocket DAW

Which operating system does Pocket DAW support?

Pocket DAW is an installed Windows desktop application. Pocket Chordsmith and Pocket DJ are separate browser apps.

Does it export game-audio packs?

Yes. The current release exports Godot and Web game-audio ZIPs, alongside WAV, MIDI, stems and section loops. Check the imported music and its timing in your target game. This DAW release does not update the separately distributed Godot addon.

Updates

2026-10-17 · GitHub release publication date in Australia/Sydney

0.6.59 - Campfire, comparison and updater fixes

Campfire Acoustic, finite passage auditions and Finish & Compare join native recording and export workflows. Warm playback reuses resident audio, stale starts are cancelled, and Undo/Redo keeps the export controls in view. This release also patches the native updater dependency and keeps background update checks from replacing active controls.

2026-10-01 · GitHub release publication date

0.6.50 — Track Sounds and Playback Recovery

Melody instrument changes now apply across the whole track and persist through save and reopen. Native stem rendering moves to a background worker, and playback can recover when a decoded asset has been evicted from cache.
