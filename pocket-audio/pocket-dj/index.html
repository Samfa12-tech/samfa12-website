Pocket DJ

Pocket DJ is an early browser performance prototype that turns Pocket Chordsmith songs into a live remix deck. Import a song export, launch sections from pads, mute stems, loop bars and shape effects as the track plays.

Use on Samfa12.com -> itch.io -> Source on GitHub ->

A performance companion

The itch listing says Pocket DJ imports Pocket Chordsmith share codes and project JSON, turns song sections into large performance pads, and supports live muting, loops, builds, drops and DJ-style section launching. It is described as a companion tool, not a replacement editor.

Prototype and platform status

The itch page calls Pocket DJ an early performance prototype, labels it In development and lists HTML5. The available listing establishes a browser build, not a native Android release.

Questions about Pocket DJ

What can Pocket DJ import?

The page lists Pocket Chordsmith share codes and project JSON.

Does it replace Pocket Chordsmith?

No. The publisher describes Chordsmith as the studio and Pocket DJ as the stage: DJ is a performance companion for songs made in Chordsmith.
