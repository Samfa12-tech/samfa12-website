Pocket Chordsmith Godot addon

The Pocket Chordsmith Godot addon imports Pocket Chordsmith JSON or PCS1 share codes into Godot chart resources. The Godot Asset Library lists it as a community tool for Godot 4.4 under the MIT license; that license applies to the addon listing, not the whole Pocket Audio family.

Pocket Chordsmith itch.io -> Godot Asset Library -> Godot Asset Store -> Addon source ->

Bring song structure into a Godot project

The Asset Library description says the addon compiles Pocket Chordsmith data into chart resources and provides beat, bar and section timing, adaptive music states, markers, cues and Godot-native sample or stem playback at runtime.

Addon licensing is distinct

The Godot Asset Library lists this addon as MIT licensed. The Pocket Audio repository says licensing is mixed across its components; check each component's license before reusing other apps, assets or code.

Questions about Pocket Chordsmith Godot addon

What input formats does it accept?

The public listing describes importing Pocket Chordsmith JSON and PCS1 share codes.

Does the MIT license cover Pocket Chordsmith itself?

No. The MIT listing is for the Godot addon. The repository describes the Pocket Audio components as having mixed licensing.
