Pocket Chordsmith

Pocket Chordsmith is a browser music sketchpad for building chord progressions, beats, bass, melodies, guitar parts, loops and longer song ideas. It offers a quick mode and a deeper arrangement mode, with exports for continuing work elsewhere.

Use on Samfa12.com -> itch.io -> Source on GitHub ->

Sketch and arrange

The itch listing describes chord progressions, drums, bass, melody and guitar, plus song sections that can be sequenced into longer ideas. Advanced tools include MIDI import and export, WAV export, JSON projects and PCS1 share codes.

Browser audio and licensing

The product page says Pocket Chordsmith runs in the browser using lightweight Web Audio instruments and that performance can vary by device and browser. Its public repository makes the app source available but does not publish an app license. The separate Godot addon has its own MIT listing.

Questions about Pocket Chordsmith

What can I export?

The product page lists compact JSON, PCS1 share codes, MIDI and WAV export. It also lists MIDI import in Advanced mode.

Does it run in a browser?

Yes. The listing describes it as a browser tool using Web Audio instruments and notes that audio behaviour can vary by device and browser. It recommends tapping Play once to unlock audio.
